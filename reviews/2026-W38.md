### 二级 / M&A / IPO

- **Sequence Holdings / Baldwin Insurance Group**：Sequence 与 Michael Dell 家办 DFO 以 **$7.7b** 收购 Baldwin。Sequence 的打法不是卖一套 AI 软件，而是直接买下成熟服务企业，再用 AI 改造运营；这是“AI-enabled roll-up”从概念走向大额控股交易的清晰案例。
- **Grab / Atome**：Grab 以 **$1.49b 现金**收购新加坡 BNPL 平台 Atome 的多数股权。东南亚支付、出行、消费信贷继续向超级平台集中，入口、数据与资金成本会比单点产品更重要。
- **OpenAI / Glass Imaging**：OpenAI 以 **超过 $300m** 收购手机相机技术公司 Glass Imaging。frontier lab 正把竞争范围从模型扩展到终端感知与图像采集链路，而不只是等待手机厂商调用 API。
- **美国国防部 / Elmet Group**：国防部以 **$450m** 买入钨生产商 Elmet 20% 股权。关键矿产与国防工业的供给安全正在从补贴、订单进一步走向政府直接持股。
- **Wonder / DoorDash**：DoorDash 一边投资 Wonder $125m，一边以 **$300m** 收购其 Grubhub Dining Campus。战略投资与资产剥离同时发生，Wonder 得到资金、DoorDash 得到企业餐饮分发资产。
- **Starbucks Japan**：Starbucks 考虑出售日本业务多数股权，估值约 **$3b**；其中国业务此前已按 $4b 估值出售多数股权。全球消费品牌正在用区域合资或出售释放资本、降低运营复杂度。
- **Syngenta**：秘密申请香港 IPO，可能募资约 **$5b**。若推进，将是中国控制的大型农业科技资产重新进入公开市场的重要窗口。
- **Altera**：Intel 与 Silver Lake 支持的芯片公司秘密提交 IPO，报道可能募资 **$2b**；AI 硬件资产的上市准备仍在推进。
- **Holtec**：核电工程公司因“市场状况”推迟原定本周定价的 IPO，原计划按区间中点约 $9.35b 市值发行。能源主题强并不意味着窗口对所有发行人都持续开放。
- **Electra Therapeutics / Orion180**：分别募资 **$350m / $240m** 完成 IPO；Orion180 定价低于区间，说明市场可以成交，但议价权仍偏向买方。
- **Anthropic / OpenAI**：Axios 报道 Anthropic 仍倾向 2026 年在 Nasdaq 上市；OpenAI 则仍偏向 2027 年，同时有早期融资谈判把估值锚到 **$1.2tn**。两家公司的资本路径开始分化为“近期公开市场”与“继续超大额私募”。
- **M&A 市场背景**：LSEG 初步数据称，Q3 全球 M&A 金额、笔数环比分别下降 **49% / 39%**；美国金额、笔数环比下降 **61% / 46.5%**。本季目前只有 9 笔 $10b+ 交易，上季为 27 笔。高利率、油价、通胀与 SaaS 重估正在压低大额交易意愿。

## ② 创业思路 + 中国对标

1. **AI 基础设施的融资正在从“买 GPU”扩展为“数据中心—网络—光互连—执行层”**：Crusoe 融 $3.9b，Cornelis 做数据中心互连，Polaris 做光互连，Temporal 做持久执行。中国创业公司不一定要复制重资产 neocloud，更可能在网络、故障恢复、任务编排、能效和资源调度中占据高复用节点。
2. **frontier model 市场开始按模态和任务分层**：Emulate 以通用实验室姿态融资，ElevenLabs 在语音/音频模型上继续扩张，而 OpenAI 的估值锚已到 $1.2tn。对国内模型公司，竞争问题从“是否做大模型”变成：在哪个模态或工作流能形成持续领先、独占数据和分发优势。
3. **AI 安全预算沿着技术栈向下渗透**：Exein 保护设备固件，Mind Security 防企业数据外泄，AIUC 服务模型和 agent 安全，Comp AI 做合规，Eve Security 做 runtime security。单一安全产品容易被平台吸收，机会在于控制真实执行点、积累攻击与误用数据，并嵌入企业审计流程。
4. **AI-enabled roll-up 可能比单纯 SaaS 更快兑现价值**：Sequence 直接收购 $7.7b 的保险经纪公司，再用 AI 改造流程。中国对标更适合从高度分散、人工成本高、数据可结构化的服务业切入，但核心能力包括并购整合、运营管理和融资，不只是模型能力。
5. **Coding agent 的资本继续集中到能够接管完整任务的公司**：Factory 估值 $5b，Boxd 做 coding agent 基础设施，Temporal 解决长任务可靠执行。国内产品若只停留在补全或聊天，会被基础模型压价；更难复制的是 repo context、工具权限、长时执行、测试、回滚和评测闭环。
6. **Physical AI 的“训练—仿真—现场优化”正在拆成独立层**：Mecka AI 做人形机器人训练，Robocurve 做机器人模型 benchmark，Treble 做声学仿真，Noetive 做工业场景自我改进，Viabot 做户外维护机器人。中国硬件供给强，软件机会在任务数据、跨设备编排、仿真到现实迁移与持续评测。
7. **AI 数据中心正在反向拉动能源技术栈**：Mazama 的超高温地热、Rune 的数据中心太阳能、Kanin 的工业余热发电、Helion 的核聚变、Branch 的商业建筑电池同时融资。短期更可落地的中国机会是并网、负载预测、微网调度、热管理和电力采购软件，而非只押注远期发电技术。
8. **制造与建筑软件的价值来自把线下状态变成可行动数据**：Caddi 结构化图纸和零部件，Buildots 用视觉追踪施工偏差，BackOps 管供应链，Adaptive 管承包商财务。国内的切入点不是再做一个通用协同工具，而是绑定高价值对象、现场数据和采购/结算动作。
9. **AI 搜索带来了新的品牌预算入口**：Profound 融资 $180m、估值 $1.8b，说明品牌已经愿意为“在 ChatGPT 等答案引擎中被看到”付费。中国对标需要同时覆盖豆包、DeepSeek、Kimi、搜索与电商内容生态，并证明曝光变化能传导到真实转化，而不是只提供排名面板。
10. **金融科技并购进一步验证规模经济**：Tabby 以 $6.5b 估值融资，Grab 用 $1.49b 收购 Atome，Footprint 用 agent 做金融犯罪调查。消费信贷前端仍可创新，但长期壁垒集中在资金成本、承保数据、合规、催收与跨场景分发。

## ③ 持续融资方向

- **Crusoe 的同一轮融资继续上调**：9 月初披露为 $3b、估值 $30b；本周更新为 **$3.9b、投后 $30.9b**。不是简单的新一轮，而是 AI 数据中心资本需求和最终募资规模继续扩大。
- **Impulse Space 第二次进入一级融资数据**：6 月融资 $500m，本周增加 $308m extension，合计 **$808m**。太空基础设施的资金正在从发射扩展到在轨运输与机动能力。
- **Wonder 第三次出现**：本周 DoorDash 追加 $125m，使本轮披露金额达到 **$775m**，并同步收购其一块资产。战略投资人既提供资金也重塑资产边界。
- **Isometric 第二次融资出现**：6 月 $40m，本周 $50m，累计 **$90m**。工业减排市场的价值不只在项目开发，也在认证、数据和交易可信度。
- **Electra 与 Orion180 从“申报/定价”走到成交**：两家公司均在历史数据中多次出现，本周分别完成 $350m 与 $240m IPO。连续跟踪比单周 headline 更能看出公开市场真实窗口。
- **AI 基础设施形成四层集群**：Crusoe（机房）、Cornelis（数据中心互连）、Polaris（光互连）、Temporal（任务执行）同周融资；资本正在围绕推理与 agent workload 补齐 GPU 之外的瓶颈。
- **安全融资从 cyber 扩展到 AI 与设备层**：Exein $270m、Mind Security $72m、AIUC $40m、Comp AI $34m、Eve Security $4.5m、TigerByte $3m。AI adoption 增加的并非单一“模型安全”预算，而是一整条数据、执行、合规和边缘设备防护链。
- **模型与 agent 应用仍能拿到高估值，但必须占据明确工作流**：Factory $200m、Profound $180m、Hang Ten $53m、Jack & Jill $40m、Magentic $18m、Aron $8m；融资重点已经从通用聊天转向 coding、营销、采购、招聘和企业落地。
- **能源继续围绕数据中心和电气化集群融资**：Mazama $135m、Kanin $60m、Helion $45m、Rune $40m、Branch $33m、Planted $31.8m、Nomos €20m。供电、储能、建设机器人与电力市场连接同时获得资金。
- **私募基金供给与交易活动出现背离**：Goldman Sachs PE 募 $9.6b、Blackstone 数字基础设施/可再生能源私募信贷基金目标 $8b、Siguler Guff 小盘并购基金超 $3b、Carlyle 基建信贷 $2.3b；与此同时 Q3 M&A 大幅放缓。资金仍多，但投资委员会对价格和宏观假设明显更谨慎。
