## ② 创业思路 + 中国对标

### 1. AI推理"中间层"正在独立成为基础设施
**现象**：Baseten（$1.5B，$12B 估值）、Groq（$650M）、Runpod（$100M，$1B 估值）、General Intuition（$320M，$2.3B 估值）、Scaled Cognition（$100M）、Engram（$98M）在同一周全部在融资——这不是巧合，是资本在系统性布局"推理即服务"。

**逻辑**：大模型训练由 OpenAI/Anthropic/谷歌垄断，但推理服务（谁给企业实际跑模型）正在成为独立竞争市场，类似 AWS 之于云计算。

**中国对标**：硅基流动（Siliconflow），国内最大 MaaS 推理服务商；另有无问芯穹（InfiniAI）。国内监管要求对模型备案，准入门槛更高，但市场同样巨大。

### 2. AI Agent 执行层开始单独获得资本
**现象**：Sail Research（$80M seed，Kleiner Perkins）做 Agent 执行基础设施；Runlayer（$30M Series A，Felicis）做 Agent 编排与部署层。种子轮 $80M 本身已极不寻常。

**逻辑**：Agent 调用工具/访问外部系统/管理长时任务，需要独立的可观测性、调度与安全层，不再只是大模型 API 调用的附属品。

**中国对标**：Dify.ai（开源 Agent 框架，国内已有大量部署）；字节跳动 Coze 走平台化路线。

### 3. 硅光子芯片迎来产业化节点
**现象**：HyperLight（$80M Series C）由全球最大芯片制造商之一 MediaTek 领投——不是纯 VC，是战略投资。硅光子用光信号替代铜互连，显著提升 AI 服务器内/服务器间带宽密度。

**逻辑**：AI 训练集群的数据中心内互连瓶颈已超越芯片本身，光互连的商业化时间表被 AI 需求大幅提前。

**中国对标**：光迅科技（烽火通信旗下）、曦智科技（Lightelligence，MIT 系）、矽宇物联。供应链安全驱动下，中国在此方向有强烈的国产替代动机。

### 4. 工业深度脱碳开始进入超大额融资
**现象**：Stegra（$1.512B，瑞典绿氢直接还原炼钢）——这是工业深度脱碳首次进入十亿美元级别融资。绿氢+直接还原铁（DRI）技术跳过焦炭，彻底消除传统高炉碳排放。

**中国对标**：宝武集团有绿氢炼钢探索，但国内氢能基础设施（输运、储存）尚不成熟；商业化节点落后于瑞典至少 3–5 年。国内更接近的机会在绿氢制备（电解槽）而非终端应用。

### 5. 自主货运无人机的国防/商业双市场
**现象**：Elroy Air（自主垂直起降货运无人机）通过 SPAC 上市，估值 $800M；同周 Twenty（无人机蜂群，$100M，$1B）和 Longshot（防务/太空 seed）融资。

**中国对标**：亿航智能（eHang）已在低空物流无人机有成熟产品；迅蚁（Antwork）做城市末端配送无人机。军用方向在国内受限公开，但商业低空经济在政策推动下是明确机会。

### 本周新冒头的结构性信号

1. **Khosla 连续双押 AI 推理**（General Intuition + Scaled Cognition）：顶级 VC 在同一细分赛道同周双投，罕见，意味着他们认为推理服务市场足够大、竞争格局尚未收敛。
2. **AI 推理基础设施从"AI"标签下独立**：本数据库 6 月才开始作为独立 sector 大量出现（Jan–May 共 2 笔，6 月单周 17 笔），说明投资人正在将其视为新的独立基础设施类别，类似当年"云计算"从"IT服务"中独立。
3. **Qualcomm 收购 Modular（$3.9B）**：芯片公司开始用 M&A 方式补充 AI 软件开发工具链，意味着软硬件一体化的竞争从 API 层向更深的开发者工具层延伸。
