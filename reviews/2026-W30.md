## ② 创业思路 + 中国对标

1. **“模型路由 + 支付”可能形成 AI 时代的新清算层**：OpenRouter 同时被多家大公司关注，Stripe 的潜在收购说明路由层不仅降低推理成本，还能掌握跨模型的计量、结算与风控。中国可对标多模型 API 聚合、企业 token FinOps、实时结算和合规审计。
2. **VC 内部 AI 工具正在产品化**：B Capital 新设 CAIO，并计划把内部 Bee Hive 投资系统的底层工具对外输出。国内基金可从投委会 memo、放弃项目追踪、创始人关系管理切入，但真正壁垒是长期决策数据而非通用模型。
3. **开放权重模型带来供应商去集中化机会**：Kimi K3 引发美国科技圈对开放模型的重新站队。创业机会不只在模型本身，也在兼容层、评测、切换、缓存与成本治理。
4. **AI 电力需求外溢到硬科技全栈**：电池材料、SMR、钙钛矿材料、节能玻璃与液冷同周融资/并购，说明算力基础设施资本开支正沿电力、散热和材料链条扩散。
5. **机器人数据与工业 agent 同时升温**：Atoms、Humanoid、Ropedia、Arrakis 等覆盖本体、工业 agent 和机器人数据基础设施；国内优势仍在制造供应链，短板是高质量操作数据与全球客户渠道。

## ③ 持续融资方向

- **多模型路由成为并购战场**：OpenRouter 在历史数据中跨 3 个日期出现，既有一级融资也有两次出售/收购讨论；其从工具层向支付与结算基础设施上移。
- **AI 芯片与推理持续吸金**：Etched 再度融资，叠加 Fluidstack、Infinity、SkyPilot 和中际旭创，资本同时押注芯片、云、调度和光互连。
- **网络安全被 agent 重做**：Neo、Twenty、Glow、Empirical Security、Abstract 等覆盖自主安全运营、身份、端点和暴露面管理。
- **能源基础设施进入“融资 + 并购”双轮驱动**：Aligned Data Centers、WildFire、液冷资产与核能/电池初创同时活跃。
- **二级市场继续承担估值发现功能**：Revolut、体育俱乐部少数股权和基金份额交易说明高估值资产仍优先通过二级流动性测试价格。
