### 二级 / M&A / IPO

- **Nvidia / Groq**：美国司法部调查 Nvidia 的 **$20b“非独家许可”协议**是否以许可加人才安排规避并购审查。若结构被否定，会影响 frontier AI 公司用 license / acqui-hire 代替正式收购的整套路径。
- **Amazon / Qualcomm**：Amazon 因数据中心基础设施合作取得可购买约 **$4b Qualcomm 股票**的认股权证。AI 数据中心的价值分配开始从 GPU 向通用 CPU、网络和系统级协同外溢。
- **Anthropic / Decart**：Anthropic 放弃约 **$6b** 收购世界模型和芯片优化公司 Decart；后者最近一轮估值 $4b。同一期还称 Anthropic 的 S-1 可能推迟至 10 月，短期观察点由“是否上市”转向申报节奏和治理披露。
- **Analog Devices / Alif Semiconductor**：ADI 以 **$1.35b 现金 + 最多 $200m earnout** 收购微控制器与 fusion processor 公司 Alif；边缘推理与低功耗计算继续进入传统芯片大厂的并购清单。
- **Bending Spoons / Miro**：以 **$1.36b** 收购曾在 2021 年估值 $17.5b 的协作白板 Miro，显示上一轮高估值 SaaS 资产在 AI 重估期的价格压缩。
- **Copart / ACV**：Copart 以约 **$1.9b 现金**收购在线汽车拍卖平台 ACV，垂直交易市场继续向规模和流动性集中。
- **Circle / Tazapay**：Circle 以 **$400m 股票**收购跨境 B2B 支付基础设施 Tazapay；稳定币公司正向商户、合规与跨境收付入口纵向整合。
- **Baseten / Blaxel**：Baseten 收购为 AI agent 提供 cloud sandbox 的 Blaxel。推理平台开始把 agent runtime、隔离执行和开发者体验纳入同一产品面。

## ② 创业思路 + 中国对标

1. **推理基础设施正在形成“芯片—光互连—电力—运行时”完整资本链**：Positron 做推理芯片，Celero 做 DSP，Ayar 做 co-packaged optics，TAR 做离网电力，Baseten 收购 agent sandbox，Amazon 又用 $4b 认股权证绑定 Qualcomm。中国机会不必复制一家完整 neocloud，更可能在推理调度、光网络、功率转换、服务器 CPU 协同或隔离执行中占据高复用节点。
2. **Frontier model 的融资越来越像国家与产业联盟，而非普通 VC round**：Mistral 的 €3b 轮次同时出现 Samsung、ASML、Nvidia、欧洲主权与多家成长基金。对中国模型公司，真正稀缺的不只是资金，而是算力、芯片供应、企业分发、政府采购和跨国市场准入能否被一轮融资共同锁定。
3. **Coding agent 的价值继续向“独立完成任务”而非代码补全迁移**：Cognition 估值 $48b，Euno 做企业上下文，Lightfield 把 CRM 设计成 agent 工作台，Cymphony 让安全 agent 执行处置。国内产品的分水岭是权限、长期上下文、工具调用、审计和回滚能否形成可靠 harness，而不是模型能否生成一段代码。
4. **AI 法律产品的高估值来自 workflow ownership**：Harvey 以 $15.5b 估值融资 $550m，买方期待的是它长期占据研究、起草、审阅、知识库与客户交付流程。国内对标要拿到律所或法务团队的任务入口、模板和反馈闭环；单次问答准确率不足以支撑类似估值。
5. **国防科技已经从“软件与无人机”扩展到导弹、太空运输和制造工具链**：Covenant、Mach、Stoke、The Exploration Co.、Poseidon、Pixxel、Ground A 与 CloudMC 同周覆盖武器、火箭、货运、遥感、反无人机和精密加工。中国对标应重点看量产速度、单位成本、任务数据和采购周期，而不是只看样机性能。
6. **消费者信贷仍有产品创新，但核心是现金流时间差**：Split Pay 不是简单增加额度，而是把每月一次的大额账单与每月两次的工资收入重新匹配，并用年轻用户专用承保模型控制损失。国内更接近的机会可能在房租、学费、车费、保险和灵活就业收入之间做现金流编排，但需要把高频需求与合规资金源同时解决。
7. **稳定币和跨境支付进入“基础设施收购期”**：Circle 收购 Tazapay，Lattitude 做跨境支付，Piston 做车队—加油站结算，Intermezzo 做全球工资 API。前端钱包越来越容易复制，护城河转向牌照、当地账户、支付路由、风控和流动性管理。
8. **Physical AI 的瓶颈在仿真、调度与真实运营数据**：Antioch 做仿真，Maven 和 Vecna 做仓储机器人，Beep 做自动驾驶接驳，ARC Ride 做电动出行。中国硬件供给强，但创业公司仍可在跨品牌调度、训练数据闭环、数字孪生和按结果付费的运营层形成价值。
9. **小型核电与数据中心正在相互抬价**：Bluecore 把小堆放到驳船上服务港口，Holtec 寻求公开上市，TAR 则绕过电网为 AI 数据中心供电。中国更现实的短期机会可能是园区微网、燃气/储能调峰、并网审批、负载预测和设备运维，而非立刻复制核能方案。

- **Cognition 第三次进入一级融资数据**：三轮披露累计约 **$3b**，本轮单次超过 $2b、估值 $48b。coding agent 已从“开发者工具”进入与 frontier model 相近的资本强度。
- **Mistral 第二次出现**：本周 €3b、投后估值超过 €21b，且投资人结构明显产业化和主权化；欧洲正在用资本联盟维持独立模型供给。
- **Mach Industries 第二次融资出现**：两次记录累计 **$900m**，本周估值 $3.7b。低成本导弹和可快速扩产的防务制造继续获得超大额资金。
- **Clay 连续两周出现**：上周披露投前估值 $7b，本周确认 $115m 融资、投后 $7.1b。销售自动化依然是 agent 最早形成规模收入和数据闭环的入口之一。
- **Groq 从连续融资走向 $20b 许可交易**：历史数据中已有三次一级融资记录，本周焦点变成 Nvidia 的大型许可安排与反垄断调查。AI 芯片公司的退出路径正在被监管重新定义。
- **AI 推理基础设施继续集群融资**：Positron $875m、Celero $275m、Ayar $150m、TAR $120m，加上 Amazon / Qualcomm 与 Nvidia / Groq 两笔战略交易，资本同时押注计算、互连、电力和生态绑定。
- **国防与太空同周形成第二个集群**：Stoke $1b、Mach $600m、The Exploration Co. $450m、Covenant $250m、Pixxel $100m、Poseidon $60m；方向从单一无人机扩展到导弹、发射、货运和遥感基础设施。
- **Agent 上下文与运行时正在变成独立品类**：Euno $23m、Lightfield $47m、Lightsage $4m、Cymphony $30m，加上 Baseten 收购 Blaxel。企业部署的竞争点逐步从模型调用转向上下文、权限、执行和可观测性。
- **大型基金供给仍然充足**：ICG €12b、Permira 首关 €9.4b、Pinegrove $1.5b、Frazier Life Sciences 超 $1.1b、Volition $950m；资产端估值分化尚未显著收紧头部机构的募资能力。
- **IPO 窗口进一步向 AI 硬资产倾斜**：Altera 可能募资 $2b，Holtec 以约 $9.35b 中点市值询价，Blue Owl 准备数据中心 REIT；与此同时 Motive 撤表、Anthropic 申报可能延后，说明市场更偏好芯片、电力与可证券化资产。
