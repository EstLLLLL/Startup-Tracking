# 一二级市场周报 · 2026 W22（5/26–5/29）

## 📈 本周大势
1. **Anthropic 登顶**：完成 **$650 亿**融资，估值升至 **$9,650 亿**（约万亿），距万亿不足 4%。Altimeter / Dragoneer / Greenoaks / Sequoia 联合领投。继上月 $300 亿后三周再追加——AI 基础模型的资本飞轮仍在加速。
2. **Cognition（Devin）同周两次现身**：周四 $10 亿 / $260 亿估值，周五再次确认——短期内最活跃的 AI coding agent 独角兽。
3. **Uber $109 亿收购 Delivery Hero**：史上最大食品外卖并购，欧洲外卖加速整合进 Uber Eats 全球网络。
4. **SoftBank $40 亿私有化 DigitalBridge**：AI 时代数字基础设施继续从公开市场回归私募。
5. **核聚变资金密集**：Thea Energy $1 亿 B 轮（stellarator）、Focused Energy $2.4 亿 A 轮（激光聚变）、Newcleo SPAC 上市（$24 亿），单周融合能源到账超 $3.5 亿。

## 💡 创业思路 & 中国对标

| 海外机会 | 中国对标 / 启示 |
|---|---|
| **AI coding agent**（Cognition/$260 亿）：AI 自主完成完整软件工程任务，已超越 Copilot 级别 | Manus AI / Trae（字节）/ Coze——国内 coding agent 估值差距巨大，下一轮融资窗口 |
| **AI 推理云**（Groq/$6.5 亿）：专为 LLM 推理设计的算力租赁，延迟极低 | 硅基流动 / 阶跃云——国内推理 neocloud 竞争已起，差异化在模型适配深度 |
| **AI 模型路由 & 市场**（OpenRouter/$13 亿）：统一 API 接入所有主流模型，计费 / 路由 / 缓存 | 302.AI / 硅基流动 API Hub——国内类似平台多，但估值 & 商业化路径仍弱 |
| **AI 音乐生成**（Suno/$50 亿）：消费端 AI 音乐创作，B 端授权 | 网易天音 / 天工 SkyMusic / 海绵音乐——中国玩家技术接近，海外商业化受版权制约大 |
| **AI 视频生成**（Reactor/$5,900 万）：面向创作者 & 广告的 AI 视频生成平台 | 可灵（Kling/快手）/ 即梦（字节）——中国团队技术全球顶尖，出海是关键 |
| **家用储能**（Base Power/$120 亿）：订阅制家用电池，对接电网调峰盈利 | 南都电源 / 正泰新能 / 比克电池——国内供应链极强，海外 DTC 储能仍有机会 |
| **Agentic 银行后台**（Saris/$2,880 万）：AI agent 替代银行中后台操作员 | 国内数字化银行 RPA 已成熟（马上消费/宇信科技），但 agent 层还早 |
| **多智能体控制层**（Canyon Code/$500 万）：为企业 multi-agent 系统提供审计、权限、回滚 | 国内企业级 AI 治理工具几乎空白，飞书 / 企微平台化后的 agent 管控层是机会 |
| **卫星激光通信**（Observable Space/$9,000 万）：星间/星地激光链路提速 | 长光卫星 / 国电高科——国内商业卫星已起步，激光通信仍偏军工，商业机会待挖 |
| **核聚变**（Thea/$1 亿 + Focused Energy/$2.4 亿）：政府 & VC 合力加注，仿星器 + 激光两路并进 | 能量奇点 / 星环聚能——国内聚变初创仍在早期，海外正在进入 B 轮规模 |
