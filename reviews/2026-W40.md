### 二级 / M&A / IPO

- **ElevenLabs**：完成 **$300m 员工 tender**，估值 **$22b**，Wellington 与 T. Rowe Price 领投。高增长 AI 应用在 IPO 前继续用结构化二级交易给员工和早期股东提供流动性。
- **Firmus**：澳洲数据中心运营商计划本土 IPO，目标至少募资 **A$5b**，估值 **A$43.7b（约 US$30.3b）**；最近一次私募估值超过 US$10.5b。若成功，数据中心资产的估值锚会进一步脱离传统基础设施。
- **Accelevation**：数据中心配电和其他基础设施公司 IPO 募资 **$540m**，但定价 $18，低于 $20–$24 区间。市场愿意接 AI 电力基础设施，但并非无条件接受价格。
- **Oura**：周二因“market conditions”推迟 IPO，与 Accelevation 的折价定价形成对照。公开市场窗口并未关闭，但对消费硬件和估值更挑剔。
- **Salesforce / Listen Labs**：Salesforce 以报道约 **$2b** 收购 AI 客户研究与 human simulation 平台 Listen Labs。企业软件大厂正购买可直接嵌入工作流的 AI 原生数据与研究能力。
- **Supabase / Turso**：Supabase 在融资同时收购 Turso，把数据库访问和 agent workload 纳入后端平台；开发者基础设施开始围绕 agent 的状态、数据和长期运行整合。
- **Nebius / Inferize**：Nebius 收购以色列推理优化公司 Inferize。GPU 云正在向推理软件和效率层纵向延伸，而不只卖算力。
- **ON Semiconductor / Synaptics**：ON Semi 计划以约 **$5.7b** 现金收购 Synaptics，较此前 $7b 全股票方案下调。边缘计算与接口芯片继续整合，但交易价格对市场波动敏感。
- **Valley National / Bluevine**：Valley National 以 **$340m** 收购小企业数字银行 Bluevine，75% 现金、25% 股票。fintech 的独立上市路径仍弱，银行并购成为现实退出通道。
- **Blockchain.com**：寻求以 **$4b–$6b** 估值 IPO，并计划今年融资 $500m；加密基础设施重新测试公开市场窗口。
- **Solidigm**：SK Hynix 的 NAND 业务筹备 2027 年 IPO，潜在估值超过 **$100b**。存储资产受 AI 数据量和供应周期驱动，开始出现超大规模资本市场预期。
- **Falcata**：Blackstone 通过收购 TSC 与 Applied Systems Engineering 组建国防科技平台，并承诺超过 **$1b** 债务与股权资本。国防科技正在从 VC 单点产品走向 PE 平台化整合。

## ② 创业思路 + 中国对标

1. **AI 基础设施的融资单位从单轮股权变成“平台资本栈”**：Helix 获 Samsung $1b、既有 commitments 超过 $10b；GMI 同时融资 $223m 股权和 $445m 信贷；Quartermaster 也是 $100m 股权加 $40m 债务。国内算力和重资产 AI 项目若仍只讨论股权估值，会低估项目对长期信贷、设备融资、战略客户和政府资本的依赖。
2. **算力瓶颈继续从 GPU 向光互连、能效与推理芯片扩散**：CScale 做光互连、Efficient Computer 做低功耗处理器、Volantis 做推理 ASIC、SiMa 做边缘 physical AI。真正的需求信号不只是“又一家 GPU 云”，而是每瓦性能、数据移动成本和端侧部署开始成为独立融资命题。
3. **开发者平台正围绕 agent 的持久状态和数据访问重新组装**：Supabase 收购 Turso，Restate 提供 durable execution，Photon 连接 agent 与应用，Doxx 管私有 agent 网络。中国对标不应只做 agent framework；更有价值的是数据库状态、身份、权限、重试、审计和长任务恢复。
4. **企业 agent 从通用助手转向高价值垂直工作流**：Metaview 做招聘、Halluminate 做金融训练环境、Outmarket 做保险、Flow 做硬件工程、Miter 做建筑劳动力。共同点是能够拿到领域数据、嵌入现有流程并对结果负责，而不是只提供聊天界面。
5. **AI 安全预算正在从模型输入输出扩展到 SaaS、身份和 agent 网络**：Armadin $255.5m、Reco $55m、Doxx $38m、Rig Security $12m、Beltic $8.8m 同周出现。企业的真实风险面是“谁代表谁、访问了什么、调用了哪些系统、是否可撤销”，安全层可能比单一模型评测更接近持续预算。
6. **稳定币产品正在从交易工具变成企业银行底层**：Jeeves 融资 $110m，F2 做机构信贷 agent OS，Walapay 做支付基础设施；与此同时 Valley National 收购 Bluevine。国内机会未必复制稳定币牌照，而是把跨境结算、资金调度、信用风控和合规数据做成企业工作流。
7. **国防科技的可融资范围从无人机扩展到感知、通信和供应链**：Quartermaster 海上监控、Fortem 反无人机、Relay 智能无线电、Foundational 卫星定位、Hop Aero 高超音速货运，同周还有 Blackstone 的 Falcata 平台。中国具备制造优势，但软件定义传感器、指挥控制和跨设备数据闭环仍是更可复用的价值层。
8. **数据中心的“电”正在形成跨 VC、PE 和 IPO 的完整资本链**：Reverion、Laki Power、Hertha 在一级市场融资；Actis 准备向印度可再生能源平台投入约 $2b；Vicinity Energy 以 $2.92b 企业价值易手；Accelevation 和 Firmus 进入公开市场。机会已经从发电扩展到并网、配电、监测、备用电源和运营软件。
9. **公开市场对 AI 相关资产的偏好正在分化**：Accelevation 能上市但低于区间，Oura 延期，Firmus却寻求激进估值。市场更愿意为有合同、设备和容量约束的基础设施买单，而不是仅凭“AI exposure”接受所有估值。
10. **consumer agent 的关键壁垒可能是信任，而不只是模型能力**：Khosla 明确把“商业模式是否与用户利益一致”视为个人 agent 的胜负手；Change.org 的实践又显示，AI 生成内容不一定比真人更有效，且拒绝 agent 自动签名。产品需要把身份真实性、利益一致和人类参与设计进系统，而不是追求全自动化。
11. **AI 平台并购开始补齐数据和推理效率，而不是只买用户**：Supabase 买 Turso、Nebius 买 Inferize、Salesforce 买 Listen Labs。对国内大厂和独角兽，下一轮并购标的更可能是能缩短工作流、提高推理效率或带来专有数据的基础层公司。

## ③ 持续融资方向

- **Supabase 第二次出现**：6 月曾融资 $500m，本周再融 $150m并收购 Turso，累计披露融资 $650m。它正在从开源 Firebase 替代品向 agent application backend 演进，数据库访问和长期状态是扩张重点。
- **Quartermaster 第二次融资**：5 月约 $43m，本周扩大到 $100m 股权加 $40m 债务。海上监控从早期产品验证进入规模部署，国防客户订单可能开始支持债务融资。
- **Outmarket AI 第二次融资**：5 月约 $17.5m，本周 $34.5m Series B。保险行业的结构化数据、合规要求和明确工作流适合形成垂直 AI 平台。
- **Relay 第二次融资**：5 月 $50m，本周 $36m。现场通信硬件与订阅软件的组合持续获得资本，说明 frontline worker 并非只能通过手机 app 数字化。
- **CVC Capital Partners 第五次进入累计交易数据**：本周既出现在 Bodycote 竞购退出，也以 Mattel 潜在买方 Authentic Brands 的股东身份出现。大型 PE 的平台资产和退出路径仍是并购市场的重要驱动力。
- **AI 基础设施沿完整堆栈融资**：Helix/GMI 提供容量，CScale 解决互连，Efficient Computer/Volantis/SiMa 优化计算，Supabase/Restate 管数据和执行，Ascerta 管支出。需求不再集中在某一个“AI infra”标签，而是由成本、可靠性和可控性逐层拆开。
- **agent 安全与身份成为独立资本集群**：Armadin、Reco、Doxx、Rig Security、Beltic 同周融资，叠加 W39 的 Island、Cyera 与 Kontext，连续两周都能看到控制面预算扩张。
- **国防与公共安全继续跨越 VC 和 PE**：Quartermaster、Fortem、Hop Aero、Foundational、Osavul、Relay、SoundThinking 与 Falcata 同周出现；资本从单一产品延伸到平台收购和长期债务。
- **数据中心电力主题继续跨市场验证**：W39 有 Kairos、ProEnergy、Accelevation；W40 Accelevation 正式上市，Firmus 启动超大 IPO，Reverion、Laki、Vicinity Energy 和 Actis 新平台同时出现。电力短缺已从主题交易变成多种资产类别的融资主线。
- **AI 应用的二级流动性继续提前**：ElevenLabs 在 $22b 估值完成 $300m tender，说明高估值 AI 公司可以在 IPO 前用机构二级资本解决员工流动性，但也把下一轮公开市场定价压力前置。
